# 🔧 ระบบแจ้งซ่อมภายในโรงเรียน (School Repair System)

เว็บแอปพลิเคชันสำหรับจัดการและติดตามสถานะการแจ้งซ่อมอุปกรณ์และครุภัณฑ์ภายในโรงเรียน พัฒนาด้วย **PHP 8 (OOP)**, **MySQL** และ **SweetAlert2**

---

## 📌 คุณสมบัติของระบบ (Features)

* **🔐 ระบบจัดการสิทธิ์ผู้ใช้ (User Roles):**
  * `Admin`: มอบหมายงาน กำหนดวันเสร็จ ดูสถิติภาพรวม และส่งออกรายงาน
  * `Teacher`: แจ้งซ่อมอุปกรณ์ แนบรูปภาพก่อนซ่อม และติดตามสถานะของตนเอง
  * `Technician`: รับงานซ่อม อัปเดตสถานะการทำงาน (`accepted` → `in_progress` → `completed`) บันทึกผลการแก้ไข ค่าใช้จ่าย และแนบรูปภาพหลังซ่อม
* **📊 Dashboard:** แสดงสถิติภาพรวมงานซ่อม (ทั้งหมด, รอดำเนินการ, กำลังดำเนินการ, เสร็จสิ้น)
* **📸 ระบบอัปโหลดรูปภาพ:** รองรับการแนบรูปภาพก่อนและหลังการซ่อม
* **🚨 ระบบแจ้งเตือน:** แสดงผลแจ้งเตือนการทำงานอย่างสวยงามด้วย **SweetAlert2**
* **📄 ส่งออกข้อมูล:** รองรับการ export รายงานเป็นไฟล์ CSV และพิมพ์ใบแจ้งซ่อมเป็น PDF
